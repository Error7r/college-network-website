# College Network Website

A multi-page static website explaining computer network concepts, built as a college assignment.

🎥 Demo video: [placeholder — add YouTube link here]

## Tech Stack

- HTML
- CSS
- JavaScript

## What It Does

- Custom animated cursor trail that follows the user's mouse
- Terminal-style animated preloader sequence on page load
- Floating animated background featuring WiFi icons and code snippets
- Responsive hamburger menu for mobile navigation
- Six interconnected pages covering topics like networking concepts, AI, and leadership

## Context

Built as a college project to pass level 2 of Computer Science at University of Technology (UOT).
